# ADR NNNN: Short title in the imperative

- **Status:** Proposed | Accepted | Superseded by ADR-NNNN | Deprecated
- **Date:** YYYY-MM-DD
- **Deciders:** who actually made the call

## Context

What is true that forces a decision? Constraints, the problem, what happens if
nothing is decided. Facts, not preferences. If the decision rests on external
information that changes (pricing, an API version, a platform's capabilities),
date it here and say when it should be re-checked.

## Decision

What we are doing, stated so someone can act on it without reading the rest.

decision.

## Alternatives considered

**Option B** — what it was, and the specific reason it lost. Not "it was worse."

**Option C** — same.

## Revisit when

The condition that should make someone reopen this. "When Cloud passes 100
tenants", "when Stripe deprecates the pinned API version", "if free installs
stall below 10k". An ADR without a trigger quietly becomes permanent.
